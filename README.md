# 批改模型生成器 (grading-model-factory)

把一堆**已批改作业范例**流水线蒸馏成可调用的 AI 批改技能。

换课程、换教师、换题型时重跑本流程即可得到一套新的「作业批改助手」。

## 它解决什么问题

老师已经批完的作业里，藏着完整的评分逻辑：锚点分、扣分幅度、加分条件、评语风格。
本 skill 把这套隐含规则反推出来，固化成可复用的 AI 批改技能。

## 产出物（四件套）

| # | 产出 | 内容 |
|---|---|---|
| 1 | 批改 SKILL.md | 评分规则（锚点+扣分/加分表）+ 评语仿写 + 输入输出定义 |
| 2 | 批改规则体系文档 | 数据基础、分布与锚点、扣分/加分表、错误分类、评语风格、信息缺口 |
| 3 | 使用说明文档 | 用途、调用方式、输入参数、输出字段、示例、人工复核点 |
| 4 | 回测报告 | held-out 抽样复批的逐份对照与一致率 |

## 十阶段流水线

```
阶段0 范例盘点  →  阶段1 格式归一  →  阶段2 文本提取
→  阶段3 批改载体探测  →  阶段4 语料构建  →  阶段5 统计分析
→  阶段6 分段深读  →  阶段7 规则合成  →  阶段8 交付物生成
→  阶段9 回测验证  →  阶段9.5 迭代校准  →  阶段10 信息缺口报告
```

完整说明见 [SKILL.md](SKILL.md)。

## 内含的实战沉淀

本 skill 的规则来自 **788 份语料、149 份盲评、六轮迭代**的真实校准过程，
包含大量已证伪的路线，可直接避开：

- **37 项实测坑位速查**（`references/pitfalls.md`）—— Word 转换、分数载体、调参翻车、多模态串号
- **调参验证速查表**——8 条「想做的事 → 结论」，其中 4 条是已证伪的死路
- **`scripts/sanity_check.py`**——回测结果质检：串号检测、评语去重、分数合法性、证据完整性，
  内置 JSON 容错解析。每轮回测跑完必须执行

## 已知边界（如实标注）

- 纯文本输入下，规则层校准的 MAE 约 3.8–4.5 分，±2 分命中率约 50%
- 中段（75–84 分）最可靠，两端（<75 高估、>90 低估）需教师兜底
- **定位是「预筛 + 评语生成」，不是「定分数」**

## 使用前提

| 项 | 最低要求 | 理想配置 |
|---|---|---|
| 已批改样本 | ≥30 份 | ≥100 份、跨 ≥2 个批次 |
| 分数可见性 | 文件名或文内任一处 | 两处都有（交叉验证） |
| 评语 | ≥10 条 | ≥100 条 |

样本 <30 份不做统计推断，只做载体探测。
